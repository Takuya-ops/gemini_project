# LINE Bot with Dify AI Integration

このプロジェクトは、LINE Botのリッチメニューを作成し、Dify AIチャットシステムと連携するPythonアプリケーションです。

## 概要

LINE Messaging APIを使用してリッチメニューを作成し、ユーザーがメニューをタップすることでDify AIチャットシステムにアクセスできるようにします。

## 機能

- **リッチメニューの作成**: LINE Botに2つのボタンを持つリッチメニューを作成
  - ヘルプボタン: "ヘルプ" メッセージを送信
  - Dify AIボタン: Dify AIチャットページへのリンク
- **画像アップロード**: リッチメニュー用の画像をアップロード
- **自動設定**: 作成したリッチメニューをデフォルトとして全ユーザーに適用
- **エラーハンドリング**: リトライロジックとログ機能

## 必要な環境

- Python 3.7以降
- LINE Messaging API チャンネルアクセストークン
- リッチメニュー用画像ファイル (`richmenu.jpg`)

## セットアップ

1. **リポジトリのクローンとディレクトリ移動**
   ```bash
   cd line_dify_test
   ```

2. **仮想環境の作成と有効化**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```

3. **依存関係のインストール**
   ```bash
   pip install -r requirements.txt
   ```

4. **環境変数の設定**
   
   プロジェクトルートに `.env` ファイルを作成し、以下を記述：
   ```
   LINE_CHANNEL_ACCESS_TOKEN=your_line_channel_access_token_here
   ```

5. **リッチメニュー画像の準備**
   
   `richmenu.jpg` ファイルをプロジェクトルートに配置してください。
   - 推奨サイズ: 2500×843 ピクセル
   - ファイルサイズ: 1MB以下推奨

## 使用方法

```bash
python line.py
```

スクリプトを実行すると、以下の処理が順次実行されます：

1. リッチメニューの作成
2. リッチメニューの可用性確認（最大60秒待機）
3. 画像のアップロード（リトライ機能付き）
4. リッチメニューのデフォルト設定

## 設定内容

### リッチメニューの仕様

- **サイズ**: 2500×843 ピクセル
- **名前**: "sample-richmenu"
- **チャットバーテキスト**: "メニュー"
- **エリア設定**:
  - 左半分（0,0 - 1250,843）: "ヘルプ" メッセージ送信
  - 右半分（1250,0 - 2500,843）: Dify AIチャットページへのリンク

## ログ

アプリケーションは詳細なログを出力します：
- リッチメニュー作成状況
- 画像アップロード進行状況
- エラーとリトライ情報
- 処理完了通知

## トラブルシューティング

### よくある問題

1. **環境変数エラー**
   ```
   環境変数 LINE_CHANNEL_ACCESS_TOKEN が読み込めていません
   ```
   → `.env` ファイルが正しく作成されているか確認

2. **画像アップロードエラー**
   - 画像ファイル（`richmenu.jpg`）が存在するか確認
   - ファイルサイズが1MB以下であることを確認

3. **API呼び出しエラー**
   - LINE Channel Access Tokenが有効であることを確認
   - インターネット接続を確認

### リトライロジック

- 画像アップロード: 最大7回リトライ（約90秒）
- リッチメニュー可用性確認: 最大60秒待機
